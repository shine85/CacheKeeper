## YYCache 源码核对

固定源码 [YYDiskCache.m](https://github.com/ibireme/YYCache/blob/0aac6e84f10b2996ef2ce906db0be1ea6ec24e83/YYCache/YYDiskCache.m) 与 [YYKVStorage.m](https://github.com/ibireme/YYCache/blob/0aac6e84f10b2996ef2ce906db0be1ea6ec24e83/YYCache/YYKVStorage.m) 已经 Git blob SHA 与 SHA256 核验。

- 磁盘工作队列是 concurrent，内部 semaphore 串行保护 KV 操作；不能套用 SDWebImage 串行队列身份条件。
- `removeAllObjects` 忽略 KV BOOL 结果；KV reset 忽略若干文件操作结果，trash 异步删除，completion 不证明实际释放。progress 版同样不检查文件删除结果。
- trim/容量上限作用于存量与周期清理，不是可靠的禁写开关。
- 这是固定上游语义，不能冒充已安装 AwemeCore 全部实现相同。运行已见 totalCost 为 uint64，而固定上游为 NSInteger，更须逐项核验。

受限观察器只观察自然 `setObject:forKey:` 与 `path` getter，固定真实 ABI/模块/偏移，不主动调用 YY 方法、不读私有ivar。写事件与路径事件分开记录，匿名 receiver 仅窗口内地址别名，不等于稳定存活 owner；缺路径触发时保留缺口。21:38 单抖音轮已运行，结果见下。
