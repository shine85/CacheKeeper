## 同一手机集中验收

1. 安装上方 154.1 包，按包管理器提示完成加载/注销，再重新启动百度网盘和 Swiftgram。正常浏览少量图片或媒体，保留原有排除项。
2. 在缓存管家点击一次“检测全部”，等待完成；再对 Swiftgram 执行 SystemData 深检并等结果。重点记录这轮是否完成及错误提示，无需手工查目录或接口。
3. 对百度依次检查自动/限制、只清理、关闭状态：每次正常浏览后切到后台并等回执，先不要立即杀进程；关闭后重新浏览，确认图片加载及业务功能恢复。不要以下载文件、草稿或聊天记录作清理试验。
4. 确认现有下载、草稿、聊天与必要离线内容保持正常；搜索弹键盘和退出编辑各操作数次。整组完成后导出一次新诊断，开发侧核对运行版本、时间、身份差异、实际 owner、提交与完成结果。发现、未触发、证据不足与确认失败分别处理。
