# 119.1 搜索宿主导航栏修复计划

目标：修复实际可见宿主导航栏覆盖搜索框的问题，恢复点按、键盘和取消按钮；分类和列表保持可用。

依据：119.1 报告 `6D6E0DFE`（SHA256 `10cb763876b22fe6e434e406a5d1255b9cbc30f934e32a63a5c2cae6ffbf1c27`）中，586 ms 时窗口和根内都命中字段；1065 ms、18927 ms 时窗口命中外层 `UINavigationBar`，根内仍命中字段。字段 y=103.667、高44；可见栏 y=53.667、高91；控制器报告的内层导航栏隐藏且没有附着窗口。134/134 savedRecords 已完成，不需全 APP 补采。

历史对照：`4b0692f` 的搜索由 navigationItem.searchController 承载；`a038391` 为允许搜索中切分类改为页面内 UISearchBar，父类完成布局后按安全区定位；`1700336` 改自有 loadView 和安全区约束；`2885ecc` 改自有输入框但保留同一顶部锚点。历史说明布局路径的变化，不据此认定某次提交已被真机二分证明为首个坏版本。

不变量：搜索与分类/列表只在本页面内布局；搜索顶部不得落入实际可见、横向相交的宿主顶部导航栏；栏缩回或隐藏时恢复安全区位置。不得固定增加47点、强抢焦点、修改宿主栏或恢复已知会遮挡分类的搜索呈现层。不扩大数据采集和资源删除范围。

方案：保留既有安全区约束，仅调整本页面一个顶部约束常量。沿未修正安全区顶边取固定左/中/右三个点，执行窗口命中查询并沿命中祖先取得真正可见的 UINavigationBar，避免只看隐藏的内层栏或漏掉宿主包装。弱引用保留本次 appearance 已实际命中的栏，每轮重新校验同窗口、层级可见性、有效矩形和与安全区顶部的交集，用当前栏下沿减原安全区顶部计算差额。临时菜单盖住探测点时不丢失已确认栏；栏隐藏、移除或移离本页顶部时清除。基准点不随搜索下移，防止偏移在0与47之间振荡；不缓存固定高度。

布局/安全区变更时重新计算，复用已有刷新处理宿主在转场后单独布局的情况；无新计时器、全窗遍历、跨层约束或全局 hook。独立方案审查已确认这种局部修正符合当前证据；不改变 additionalSafeAreaInsets 或宿主布局。
