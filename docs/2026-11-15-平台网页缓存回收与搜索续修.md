# 平台网页缓存回收与搜索续修

本轮按用户要求优先增加实际缓存回收能力，同时修复搜索下移、完善限制与清理结果反馈。源码验证、云端构建与当前手机实测分别记录。

## 网页磁盘缓存

新增每 APP 独立选项“切后台回收网页缓存”。缺省关闭，旧配置升级、一键开启、模式和总开关切换都不会自动授予它。开启此选项及 APP 总开关后，实际使用网页再切到后台，由该 APP 内真实 WKWebView 的数据存储执行系统 `WKWebsiteDataTypeDiskCache` 回收。

- 只请求平台网页及媒体磁盘缓存，不请求 Cookie、网站数据库或离线网站存储；网页可能需要重新联网。
- 不创建默认 store 猜测目标，不遍历网页 URL，不改变文件清理对 WebKit 目录的保护。
- 存在任何手动目录保留时不提交，因为系统接口无法表达路径排除。配置无效、安装身份失配、无后台时间或未观察到真实持久 store 时记录具体原因。
- 同一 APP 串行处理，重复后台事件不重放。等待超时仍保留未结束请求；晚回调归原请求，关闭再开启不能绕过。
- 冷启动复用同步读取的独立授权，立即接入创建观察；身份验证前只保存最多 32 个弱引用视图，验证后才读取真实数据存储。关闭或新配置使旧异步结果失效。
- 每次系统调用从实际提交时安排自己的 15 秒等待期限；预检耗时、上一数据存储的旧定时器不会提前结束当前等待。回执提交数必须等于完成数加在途数。
- 回执与文件清理、NSURLCache 限制分开。系统完成回调不提供删除项数或物理释放字节，界面和诊断均标记未测量。

旧 NSURLCache 选项增加带原始时间的“上次应用结果”，区分容量置零、限制未生效、未限制/恢复、恢复待重试。该结果是历史回执，不能替代当前 APP 重新运行后的核查。

## 搜索下移

136.1 手机诊断中，祖先导航栏始终为 91pt；574ms 至 1004ms 间交互从禁用变启用，搜索下移 47pt。不能解释为这一段导航栏刚刚增高。

[Actions #137](https://github.com/shine85/CacheKeeper/actions/runs/43687998638) 在旧产品源码上有效复现：包装控制器转发 `navigationItem` 后，真实栏仍持旧 item，紧凑认领却被释放。新增用例 6 条预期行为断言失败，14 个旧探针和 5 个 XCUI 通过；未以夹具失效或编译失败冒充复现。

修复围绕完整当前控制器分支与实际栏 item 的统一归属判定。保留宿主显式大标题、转场和离页恢复；几何避让不再受祖先栏临时禁用交互影响。新增诊断记录有限布局与归属状态，不记录搜索内容或宿主标题。

导航项与栏的原值分别按对象身份继承，覆盖同栏换项、同项跨栏及宿主仅改标题模式的情况；宿主后来明确开启的大标题偏好也不会被旧值覆盖。

## 当前设备资料

已通过既有 SSH 连接完成集中补缺并关闭连接。覆盖 304 个当前注册条目、302 个可获得的主程序镜像头、61 个 SDK 技术元数据及 410 段未加密指令，同时保留 1,386 份旧百度/Swiftgram 等资源证据。资料只含注册、安装、容器、容量和组件技术信息，不含用户聊天、文档、数据库记录、账号或日志正文。

本地自包含档案为 `packages/device-audit-2026-11-15-complete/`，2,903 个归档文件及引用经独立校验通过，采集器 72 项离线测试通过。既定可读范围没有未采完项；两个注册包缺主执行文件、五个 APP 缺版本字段、四个 APP 中六个 SDK 的加密区段都有明确记录。没有解密，也未把固定动态 SDK 候选筛选视为全部静态链接 SDK 覆盖。档案保持本地保存，不上传 GitHub。

静态采集覆盖与运行时接口可用性分别列明。应用升级后的增量检查复用安装身份与统一诊断；静态识别不等于回收规则已完成。

## 验证与交付条件

Windows 本地原生与 UIKit 入口实际返回 UNAVAILABLE。新增核心状态机、配置往返、严格回执导出和 UIKit 公共 API 用例须经同提交 macOS Actions 验证，RootHide 编译与 deb 内容另行核验。当前文档不声明云端 GREEN 或真机已修复。

下一测试包在手机上的检查步骤：

1. 搜索页进入后停留数秒，输入、取消、进入 APP 详情后返回，再做一次前后台切换，确认位置和点击稳定。
2. 对没有手动保留目录、确实使用网页的 APP 单独开启新选项，重开 APP、使用网页并正常回到桌面，返回详情查看回执。
3. 检查网页重新联网可加载，Cookie/登录和网站数据正常；重复三轮。关闭新选项后不得提交新动作，已有未结束回调仍按原请求报告。

既定剩余项仍包括 PDF 真机权限/取消/离页/Filza、闭合硬链接真机操作、必要数据保持及 iOS 17 验收。最终产品还缺百度下载副本、Swiftgram 媒体事务与其他私有资源契约；新的平台 DiskCache 能力不替代这些完成条件。
