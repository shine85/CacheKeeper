# 全容器计量与资源效果整组实施

## 依据与边界

设备 2026-11-19 只读采集：305 登记 APP，排除风起云涌，304 核查；1156 根身份，1155 完整、1 不完整，21 APP 无登记数据根。百度 Documents 已分配 2.660 GB、QQ Documents 1.192 GB；抖音 Application Support 0.512 GB，主要匿名子树用途未知。不得把这些数字称为可清理量，也不得把目录完整计量称为系统存储完整归因。

现有候选扫描跳过受保护文稿；诊断只投影已有记录。新增能力必须与删除权限完全分离。用户已要求直接完成既定整组方案，不重新询问已确定的设计，不重复本次 SSH 盘点。

## 实现方案与不变量

采用同一次安装 provider 提供私有容器计划，既有 FD-relative 分片 cursor 扩展元数据观察器，独立容量任务/请求/结果；诊断增加主动测量入口并保留旧记录汇总。相比将 Documents 加入候选扫描，此方案不会扩大删除范围；相比另起 LS 解析器，此方案不会增加容器归属第二事实源。

1. 容器 URL 只来自既有 LS provider；私有计划仅留服务进程内存，客户端请求不允许路径。公开输出仅 bundle、匿名根/节点 ID、固定目录类别和数值。
2. 全登记来源包含非展示 APP、Group、扩展；排除风起云涌。没有容器、来源不完整、不可读、身份变化、预算耗尽均明确，不填零伪装成功。
3. 测量不读取普通文件内容、不改配置/权限、不唤醒 APP、不触发清理；末级 NOFOLLOW、打开前后身份核对、切片前后变化核对沿用生产 cursor。
4. 每根逻辑量和 st_blocks×512 已分配量单独报告，根内 inode 去重。共享根只测一次，多 owner 关联不相加为全机总量；跨根硬链接/APFS extent 唯一量与实际释放量未测，不用分配量代替。
5. 标准 Documents、Library、Caches、Application Support、tmp 固定类别可展示；未知名称匿名化，匿名层次有独立预算。用途、可重取、引用关系未建立时明确保留，不因目录名或 API 方法存在放行。
6. epoch、源采样时间、开始/结束、进行中/完整/部分/取消/重启中断分开。停止关闭 FD；取消后重新测量新 epoch，不假装持久化 FD 可恢复；离页停止，晚结果不能覆盖新任务。
7. 保存与导出不重新读容器；导出保留原 epoch/时间，标记已保存观测，不声称导出时仍新鲜。
8. 新装/升级/同版结构变化通过同一 provider 和每轮 root 身份观察重新核验；发现不授清理权限。未知私有资源与宿主来源缺口仍需独立可信证据。

补充边界：provider 的 dev/ino 绑定实际打开 FD 的首条元数据，不只依赖路径前后复核（防中间别名 ABA）；不匹配时没有容量累加并立即关闭 cursor。取消只作用于活动同 epoch；已有保存结果时陌生 UUID 的 cancel 无顺序证明，不能覆盖当前/已保存结果，包括冷启动。服务从未观察新 start 就收到 cancel 时，页面可能只得到“停止未确认”，不会以别轮终态冒充；新测量始终要发新 start。

## 任务与验收门

| 任务 | 范围 | 验收 |
|---|---|---|
| T1 元数据计量 | cursor 观察接口、独立根统计/匿名层次、真实 FS fixture | 普通/稀疏/硬链/目录/链接、身份变化、取消/预算、名称不泄露；精确行为 RED |
| T2 唯一 provider | Installation 私有计划，同次 registry | 全角色归属与公开 token 一致；无第二次枚举；矛盾归属拒绝 |
| T3 服务与面板 | Scanner 独立只读任务、请求校验、诊断主动采集与导出 | 取消/替换/失败/重启、非零测量、坏请求不访问容器、离页/晚回调 |
| T4 效果回归 | 平台/网络/图片/WebKit 三模式真实测试与资源准入复核 | 只清理→限制并清理→关闭：真实存盘/删除/恢复、必要数据保留；不以开关/API 回调代替效果 |
| T5 集中交付 | 整体复核、统一普通推送、同提交 CI、deb 验包 | 原生/UIKit/SDK16.5/RootHide 双架构分别核实；失败集中修复后复验 |

Windows 没有 xcrun/Foundation/UIKit，不用 Python 编排测试冒充 Objective-C 实测。先写行为测试，能执行的本地真实测试先执行；缺失环境在账本明确 UNAVAILABLE，原生 RED/GREEN 与整套回归须在同提交 macOS 完成，编译失败不能当 RED。

## 上游接口依据

既有固定证据可复用并核对当前代码：
- [RootHide LSBundleProxy](https://github.com/roothide/headers/blob/e1132e2bbc3ca15c50e2311bcd349cb7353409e1/MobileCoreServices/LSBundleProxy.h) / [LSApplicationProxy](https://github.com/roothide/headers/blob/e1132e2bbc3ca15c50e2311bcd349cb7353409e1/MobileCoreServices/LSApplicationProxy.h) / [LSPlugInKitProxy](https://github.com/roothide/headers/blob/e1132e2bbc3ca15c50e2311bcd349cb7353409e1/MobileCoreServices/LSPlugInKitProxy.h)：复用现有 dataContainerURL / groupContainerURLs / plugInKitPlugins 的归属校验，不增加第二次容器枚举；系统登记关系仍非实际读取/清理授权。
- [WebKit WKWebsiteDataStore](https://github.com/WebKit/WebKit/blob/7a88d3bffee3b701a9288ceda2b5e6b4381ddc02/Source/WebKit/UIProcess/API/Cocoa/WKWebsiteDataStore.mm)：数据类型、提交与 completion 不是磁盘限制或释放证明；宿主与 iOS 生命周期必须独立测量。
- [SDWebImage 5.19.1 SDImageCache](https://github.com/SDWebImage/SDWebImage/blob/5.19.1/SDWebImage/Core/SDImageCache.m)：缓存实例、目录与异步队列语义，不能把版本/API 名存在等同应用使用该实例。
- [Foundation URLCache 实现参考](https://github.com/swiftlang/swift-corelibs-foundation/blob/af244645c3a883daff9f8631e6163fdefa574718/Sources/FoundationNetworking/URLCache.swift)：仅作接口对照；Linux 实现不证明 iOS 宿主磁盘行为，新增实现不得据此放宽准入。

## 最终目标仍有的证据缺口

未知私有目录的实际用途、引用/保留/可重取条件；百度图片活 owner 与原始实现来源；Swiftgram 私有共享媒体契约；跨根/APFS 唯一 extents、安装资源/孤立容器/打开未链接文件与系统存储归因；目标 iOS 17 真机。必须据实际测试逐项收敛，不能将本次新增计量称为上述全部已解决。

现有真实 SDWebImage 多版本与 WebKit 集成套件继续整体回归，不用新元数据计量替代它们。新全容器入口不启动 APP、清理、改模式或授予沙盒权限。每根 200 万条/64 层/262144 inode/4096 匿名节点/300 秒；整轮 1800 秒、4096 根、65536 节点；触顶终态部分，单次系统调用不可抢占。

### 新包成功验包后的一次集中实测

1. 保持原配置，进入“设置 → 缓存管家 → APP 目录页 → 全容器·只读”（也可原诊断入口），点“重新测量全容器占用 · 只读”。停留前台直到完整/部分终态；点“汇总已保存诊断 → 导出报告”，命名 `基线-全容器.json`。无需手工盘点目录，304 APP 范围由程序获取；数量以本轮登记为准。
2. 在同一目标 APP 详情“缓存控制”中依次测试 **只清理 → 限制缓存并清理 → 关闭该 APP 开关**，不是全容器按钮。“自动”与限制模式共用限制决策，可另作恢复对照，不把它当第四种删除授权。各阶段保持 NSURLCache/网页选项与目录选择一致、使用相同浏览动作和时长、切后台等待回执；先保持后台，不立即划掉以免不给后台 API 执行机会。
3. 每阶段重新运行一次全容器只读测量，再汇总导出，命名 `只清理.json`、`限制并清理.json`、`关闭恢复.json`。关闭阶段确认能正常打开必要文稿、消息、草稿/下载与账号，缓存可重新写入；不用重复下载个人文件。容量变化只是观测，结合本轮宿主/操作回执判断是否触发，未触发与失败分开。
4. 补一次“开始 → 停止 → 新轮”与返回/后台测试，可并入 `取消重试.json`。旧 epoch 不能算新轮成功；无确认应展示停止未确认，不永久锁页。PDF/分享原流程不应被计量入口影响。

开发侧收到这些报告后，按 rootIds/匿名节点和各自原时间自动关联，不再要求用户搜目录或准备同版本安装包。若私有用途证据仍缺，只保留并明确缺少哪项 owner/引用/重取证据；这不是可用容量可任意删除的证明。上述步骤仅在新包完整云端验证和验包成功后执行，不让用户试失败基线。
