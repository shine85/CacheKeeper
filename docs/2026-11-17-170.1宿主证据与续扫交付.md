## 一次集中真机验收

1. 安装 **0.7.2-170.1**，按包管理器提示完成加载，重新启动目标 APP；先确认面板版本。开发侧本轮没有代安装、改变手机开关或删除资源。
2. 点一次“检测全部”，等待批量结束；对汽水音乐、抖音查看本次进度、完成时间与终止原因，必要时各发起一次单 APP 检测。已有保存值不是新结果；达到预算应明确“部分/上限”，不能静默显示完成。
3. 分别在 Swiftgram、百度页面点“查看／检查宿主（只读）”，按提示打开该 APP 使用后及时返回查看。保留在途请求期间不主动跳到其他设置页；随后另测离页重进与取消返回。核对当前版本和时间，不能用 154.1 旧记录替代。该入口不修改策略，和“检查网络限制”不同。
4. 在已授权、可重新获取的缓存范围集中验证限制模式、只清理、关闭后的正常写入；每组使用相同浏览操作，切后台并等待本轮回执，再划掉重启。确认登录、消息、下载、草稿和必要离线内容保持，不把这些数据作为删除试验。搜索输入、取消和重进一起检查。
5. 完成后一次导出诊断，由开发侧比对本次版本、进程与动作、续扫覆盖和失败原因；无需手工找目录、接口或准备 IPA。资源前后元数据核验仍由开发侧对已证明归属的 owner 在明确授权范围完成。

无响应、未触发、旧回执和明确失败分别记录；没有真实 owner 或文件前后证据时，不把 API 完成、容量零或逻辑字节变化当成实际物理释放。
