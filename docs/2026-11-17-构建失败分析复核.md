- #167 是 ScanPageTests 新增测试文件的 XCTest 宏参数编译错误；Objective-C 字面量或消息中的逗号应先抽为局部变量或用圆括号隔离。b8988b3 已修此问题，#168 编译已通过。

- Windows 本地没有 UIKit Simulator，原生和 UIKit 的真实执行必须由 macOS/Xcode 提供；本地编排通过不等于行为通过。
