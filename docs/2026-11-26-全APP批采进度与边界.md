## 本次暴露的工具缺陷

1. SDK 阶段没有独立汇总，主身份的 `collected` 容易被误读为 SDK 已采完。
2. 中断后统一写 `notAttemptedConnection` 会覆盖缺主身份的首要原因；本地准备或写回失败后的未尝试项也没有完整标明。
3. 入口没有断点续采，每次重跑会重复主身份及已成功 SDK 检查。续采需保留源报告，绑定其 SHA，仅补明确未尝试且有主身份的项，当前身份改变不得升级为成功。
4. 25 个主身份失败都被合并为 `registrationOrMetadataUnavailable / exit 1`，底层没有保存失败阶段。现有回执无法进一步判定原因，不能猜作权限或文件不存在。

本地已补 SDK 独立汇总、失败后状态分类和 `--resume` 元数据续采。批次与续采 22 项测试通过；主流程独立执行批次、续采、可移植性、SDK 四组共 36 项通过，并对最终入口再跑 9 项续采测试通过。真实父报告仅离线解析即可确认 205 个待采项，未加载传输时不会产生设备任务。旧失败、结果未知和部分完成的项不自动重试，也不修改原报告。
