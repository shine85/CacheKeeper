# 旧版图片缓存契约实施计划

> 继续已授权的整组修复；各子任务独立实施和复核，完成后统一提交、推送与构建。

目标：在现有扫描、身份诊断和 Hook 发布修复上，加入有明确来源与运行时边界的旧版图片缓存适配，推进百度实际资源能力。

规格：[占用扫描与资源识别续修](2026-11-16-占用扫描与资源识别续修.md)。沿用 Objective-C、Theos、iOS 16–17、SDK 16.5、RootHide 与现有包身份。

## 决策与不变量

- 不从缺少 `ioQueueAttributes` 推断串行。显式区分现代配置队列契约与已采证据支持的固定串行旧契约。
- 百度目标为本机 13.37.5 / 13.37.5.10 的准确镜像；实际 SDK 版本未知。5.10.4 是固定的上游行为测试来源，不是百度版本标签。
- 生产准入核对主镜像身份、UUID、方法偏移及已采字节窗口；未核验范围不接纳。窗口哈希不称为完整函数证据。
- 保留稳定的 25 槽方法索引；旧契约第 11 槽必须明确缺席，之后出现同名 getter 即撤销资格。
- 只被动观察真实 owner 初始化；构造前后的配置、标准 backend、队列身份、路径身份、安装身份、当前授权和保留范围全部保持门控。
- 不扩大到百度下载副本、Swiftgram 消息数据库或未知业务资源。不执行手机安装、开关、清理或限制动作。
